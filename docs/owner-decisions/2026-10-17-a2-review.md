## 2. 对你五个问题的裁决

### 2.1 可读性约束：接受"以描边为准"

你的分析正确：L* 25 的主色下限与设计卡配色在数学上不可同时满足，而实机证明 3 px 描边已足够。ART-SPEC 8.1 已改为：描边色与格底色 L* 差 ≥ 25 为强制项，主色差为报告项。ADR-015 第 3 条可标记为已确认。

### 2.2 SPEC 音效表：批准，并定为规则

SPEC 13 的音效表是 SPEC 中唯一允许实现者直接追加行的地方（新增音效必须同时登记 ART-SPEC 12 与 `SOURCES.md`）。AGENT.md 第 7 章已写明这个例外。其余 SPEC 内容仍只读。

### 2.3 CI 像素容差：批准，加一条限制

macOS / Windows 允许 0.1% 像素偏差、Linux 逐字节：批准。限制：容差只适用于 `art_assets_up_to_date` 这类渲染比对，**`determinism_golden_1_4` 等模拟层快照在三平台仍必须逐字节一致**，不得套用同一容差。ADR-013 修订处补这一句。

漏过格式检查那次：以后提交前的检查链用 `&&` 串联或写成 `scripts/precommit.sh`，任何一步失败即不提交。

### 2.5 音效时机与性能

音效统一按花园皮肤事件帧、两种皮肤一致：批准，这正是"音效跟动画事件帧"的本意。占位模式比 G5 慢一倍仍远低于上限：记录即可。听感待负责人。
