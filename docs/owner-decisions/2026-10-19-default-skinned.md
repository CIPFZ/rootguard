# 负责人裁决 2026-10-19（十）：默认渲染模式改为 Skinned，发 v0.2.1

> 发给 Rootguard 实现者。SPEC 已升到 v1.3（12.1）。**本裁决优先于其他待办，立即执行。**

## 1. 问题

负责人安装 v0.2.0 后看到的仍是几何占位体。原因：SPEC 12.1 规定 `SkinMode::Placeholder` 为默认，新存档与 0.1.0 旧存档都停留在占位模式，玩家必须进设置切到"几何 / 花园"才能看到 garden 皮肤。这是 SPEC 的陈旧规则，负责人审核时未发现其后果，不是实现错误。

## 2. 决定

1. **默认渲染模式改为 `Skinned` + `garden`**（SPEC v1.3 12.1）。`SkinMode::default()` 返回 `Skinned`。
2. **存档迁移**：`Progress::VERSION` 升到 2。读取 v1 存档时，`settings.skin` 一律置为 `Skinned`、`skin_name` 置为 `Garden`（不区分用户是否手动选过占位，0.1.0 没有理由主动选占位）。v2 存档照常读取。`.bak` 备份逻辑不变。
3. Placeholder 保留为设置项、CI 截图与所有 headless 测试的基准，**测试里显式指定模式的地方不要改**；只有依赖 `Settings::default()` 的测试需要同步。golden 不受影响（渲染模式不进模拟）。
4. 设置界面的文案调整：当前三档显示为"占位 / 几何 / 花园"，把"几何"改为"几何（0.1.0）"，"花园"排在最前并作为默认高亮。
5. 顺手：标题与结算画面的灰色占位按钮改为木牌风格（裁决九第 2 节）。

## 3. 发布

- `CHANGELOG.md` 新增 `[0.2.1]`：默认画面改为花园皮肤；旧存档自动切换；菜单按钮木牌化。
- workspace 版本 0.2.1。
- 完成后停下，通知负责人打 `v0.2.1`。一次会话内完成。

## 4. 验收

新装（无存档）与带 0.1.0 存档两种情况启动后，不进设置直接开始 1-1，画面为 garden 皮肤。各截一张入 `docs/screenshots/v021-fresh.png` / `v021-migrated.png`。
