# ADR-017：A3 战场精灵、HUD 皮肤与叙事画面的落地

- 编号：ADR-017
- 标题：A3 战场精灵、HUD 皮肤与叙事画面的落地
- 日期：2026-10-16
- 状态：已接受

## 背景

裁决（八）第 3 节放行 A3：ART-SPEC 8.1 L4 ～ L6、8.3 HUD、8.2 时段色调、8.4 关卡独白 / 结局 / 标题背景，以及咬夹草 `burp`
与门板碎片单测。这些都是单帧画面或纯呈现，不进入模拟层。

## 决策

1. **单帧精灵管线**：`art/bg/scene/`、`art/ui/`、`art/story/` 各有 `sprites.ron`（名字、归一化锚点；SVG 的 `viewBox`
   即尺寸），与角色部件同一套颜色校验（`bg::render_sprites`）。战场精灵打成 `garden_scene`（片段 `scene_<名>`），
   叙事画面打成 `garden_story`（`story_<名>`），HUD 精灵与卡牌头像同在 `garden_ui`（`ui_<名>`）。
2. **战场**（ADR-015 第 6 条）：外墙、入口、前景在背景层；阀门按 `LaneState.hose_available` 两态；门柱在世界层、排在同行
   Husk 之后，Husk 从门后走出。
3. **HUD**：布局常量不变（点击区域与占位模式一致）；皮肤有 `ui_hud_bar` 时画木条、木牌卡槽 + 卡牌头像（不可用时去饱和）、
   露珠图标、园丁小铁铲、藤蔓波次条（`Painter::draw_in` 按进度裁出左段）、吊挂木牌横幅。铲子 / 暂停仍是 egui 按钮，
   皮肤 HUD 下无边框（`scenes::button_styled`），压在 `DrawList` 的木牌上；铲子按钮只显示铁铲图标。
4. **时段**：`LevelDef.time_of_day`（ART-SPEC 12 允许的可选字段，`#[serde(default)]` 为 `Morning`）；模拟不读取，golden
   不变。叠层画在 `Layer::OVERLAY` 下一层，只在皮肤模式画。
5. **关卡独白**：Intro 横幅文字为 `level.<id>.intro`（缺失时回退“准备”），字号 22（大波提示 30），横幅木牌加长到 900 px；
   中文取 LORE §4 原句，英文为实现者翻译并控制在 900 px 内。文本增加新汉字后 CJK 子集字体必须重新生成：新增测试
   `cjk_font_covers_text_tables` 直接解析字体 `cmap`（格式 4 / 12），不依赖开发期的 fonttools。
6. **结局**：`OutcomeScene::with_ending`（最后一关胜利，即没有下一关）。皮肤模式画结局背层、日灯笼（idle 身体 + 最亮的
   `produce_gold` 叠层帧，放大 1.6）、小芽怪、前层土埂、底部木牌上的 `ending.line`；按钮移到玻璃墙空处。占位模式把这一句
   写在提示行。标题背景（`story_title_bg`）只在皮肤模式画，标题文字写在背景上方的吊挂木牌处。
7. **咬夹草打嗝**（ART-SPEC v1.3 4.10）：`chew` 片段末帧事件 `burp`；`chew` 按游戏时钟循环，事件每个循环都会发出，
   呈现层只在咀嚼计时器剩余 ≤ 一个循环（60 tick）时生成 `burp_bubble` 特效——每次咀嚼恰好一个。叶齿残影由 `snap` 片段自带。

## 后果

- 新增精灵只需写 SVG 并登记到对应的 `sprites.ron`，游戏端按片段名绘制；皮肤缺失时全部回退占位图形。
- 结局与标题画面的构图为实现者自定，只取 `v3-key-visual` 的调子（ART-SPEC 9.3）。

## 替代方案

- 结局静帧把日灯笼与小芽怪也画进 SVG：与角色造型重复且易走样，否决，直接用角色精灵。
- 独白横幅自动换行：引擎文本无测宽接口，按估算换行在中英文下都不可靠；改为控制句长 + 加长木牌。
