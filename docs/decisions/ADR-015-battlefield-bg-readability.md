# ADR-015：战场底图 bg_base 与 8.1 可读性约束的落地

- 编号：ADR-015
- 标题：战场底图 bg_base 与 8.1 可读性约束的落地
- 日期：2026-10-16
- 状态：已接受；第 3 条已由负责人裁决（八）2.1 确认，ART-SPEC v1.3 8.1 已改为“以描边为准”

## 背景

裁决（七）第 4 节：A2 开始时先按 ART-SPEC v1.2 8.1 战场设计卡产出 L0 ～ L2 静态底图 `bg_base.png` 并接入 garden
皮肤。设计卡规定：L0 天空“竖向两色渐变”；L2 草地格列 3 ～ 5“线性过渡”；新增背景专属色；以及“任一格底色与
任一角色主色的明度差 ≥ 25%（`artgen` 对 21 个角色主色逐一校验）”。现有管线不允许渐变与调色板外的颜色
（ADR-013 第 2 条），专属色每角色 ≤ 2。

## 决策

1. **L0 与 L2 由 `artgen` 按设计卡公式生成**（`tools/artgen/src/bg.rs`）：天空为 `sky_top` → `sky_bottom` 的
   竖向渐变；草地 5 × 9 格的几何直接取游戏的 `rootguard_core::Grid`（原点、格子尺寸），列 0 ～ 2 为 `leaf` /
   `leaf_light` 降 10% 明度、列 6 ～ 8 为 `grass_dry` / 其降 10%，列 3 ～ 5 线性插值，棋盘交替，行间 3 px
   `leaf_dark` 土沟线。这些颜色由调色板与公式唯一确定，不是手写值。L1 远景 `art/bg/far.svg` 是手绘部件，
   与角色部件同一套校验（只允许 `@名`、合成后逐个检查颜色）。格子区以外暂填 `leaf_dark`，L4 ～ L6 在 A3 覆盖。
2. **背景专属色**放在调色板新的 `background` 段（`sky_top` / `sky_bottom` / `grass_dry` / `brass`），只供背景
   使用，不受“每角色 ≤ 2”的限制（该限制针对角色）。
3. **可读性约束的冲突**：按设计卡的配色，18 种格子底色的 CIE L* 落在 62 ～ 77；21 个角色的主色（默认位姿中
   占比最多的非描边颜色）除块茎雷外**全部**达不到 25 的明度差（最好的树皮墙 19.5，石籽荚 0.4、枯壳怪 2.5）。
   这不是个别角色的问题：L* 在 37 ～ 100 之间的任何颜色都不可能同时与 62 ～ 77 相差 25，而几乎所有角色主色都
   在这个区间。只换格子色或只换角色主色都无法满足，必须改设计卡本身（例如格子明显变暗）。处理：
   - **强制项**：两种描边色（守卫 `outline` L* 23.0、Husk `husk_outline` 25.6）与每种格子底色的明度差 ≥ 25，
     不满足即拒绝生成——3 px 深色描边才是角色从格子里“跳出来”的实际原因（39.2 / 36.6，满足）；
   - **报告项**：每个角色主色的最小明度差写入 `docs/art/bg-readability.md`（随 `artgen build` 生成、受
     `art_assets_up_to_date` 约束），`build` 输出未达标数量；不阻塞。
   - ~~请负责人在实机底图上判断可读性后决定~~ → 裁决（八）2.1：接受“以描边为准”（已确认）。
4. **游戏侧**：花园皮肤有 `bg_base` 片段时，`draw_background` 画全屏底图并叠加 L3 非激活车道遮罩（40%
   `#1E2A1A`，渲染层颜色，不烘焙进图），不再画占位色带与格线；温室外墙、入口与 Hose 标记两种模式暂时共用
   占位图形。占位模式不变。测试 `garden_background_drawn_with_lane_mask`。
5. 底图是单帧图集 `garden_bg`（图像文件按裁决命名为 `bg_base.png`），不走货架打包。

## 后果

- 格子几何与模拟用的是同一组常量，网格与底图不会错位。
- 可读性约束目前只有描边部分在构建时把关；主色表随资产变化自动更新，负责人可直接查看。

## 替代方案

- 天空用若干横条近似渐变：中间色同样不在调色板，且出现色带，否决。
- 把渐变 / 过渡色逐个加进调色板：19 个派生色，配色一改就要同步，否决。
- 让主色约束强制生效：按现配色一个角色都过不了，等于不能产出底图，否决。
